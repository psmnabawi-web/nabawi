Pengaturan

Sumber parameter (Google Sheet)

Sheet harus dibagikan “Siapa saja yang memiliki link: Pelihat”. Disimpan hanya di browser ini. Untuk tim: kirim link aplikasi yang sudah membawa sumber parameter (tombol di bawah); cukup dibuka sekali per perangkat.

Data bersama tim

Semua perangkat dengan kode tim yang sama melihat file Zahir terbaru, perubahan Final PR/catatan, dan nomor PO yang sama. Kode ikut di link aplikasi untuk tim. Jangan bagikan ke luar tim; bila bocor, buat kode baru lalu kirim link baru ke tim.

Perhitungan

Buffer + Lead time (default): order dipicu saat SOH ≤ ROP, Kebutuhan = pemakaian × (buffer + lead time) − SOH, persis parameter master. Target DSI tetap dipakai sebagai KPI dan status “Di atas target”. Pilihan “Target DSI”: stok maksimum = pemakaian × (MAX(buffer + 1, 2 × target − buffer) + lead time), rata-rata stok fisik = target. Target per item bisa diisi di kolom “Target DSI (Hari)” master.

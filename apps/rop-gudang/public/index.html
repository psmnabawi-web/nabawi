Pengaturan

Sumber parameter (Google Sheet)

Sheet harus dibagikan “Siapa saja yang memiliki link: Pelihat”. Disimpan hanya di browser ini. Untuk tim: kirim link aplikasi yang sudah membawa sumber parameter (tombol di bawah); cukup dibuka sekali per perangkat.

Perhitungan

Target DSI = rata-rata stok fisik (hari pemakaian), sama dengan KPI DSI gudang. Order dipicu saat SOH ≤ ROP, lalu ditutup sampai stok fisik maks (pemakaian × MAX(buffer + 1, 2 × target − buffer)) + pemakaian selama lead time. Target per item bisa diisi di kolom “Target DSI (Hari)” master. 0 = sama dengan sheet lama.
